# Governance

Beans Proxy is maintained by Platform (Platform Studio Inc) with contributions from the community. Governance is intentionally lightweight so a small team can make decisions and ship fixes without unnecessary process.

## Roles

- **Contributors** report issues, propose changes, and submit pull requests.
- **Maintainers** review and merge changes, manage releases, handle security reports, and set project direction.
- **Platform** appoints maintainers and has final responsibility for the repository and its published packages.

Maintainers are the members of the [Platform-Studio GitHub organization](https://github.com/Platform-Studio) with write or maintain access to this repository. GitHub permissions are the authoritative list.

## Decisions

Routine decisions happen in issues and pull requests. Maintainers seek practical consensus, considering user impact, compatibility, security, maintenance cost, and alignment with the project direction. When consensus is not reached promptly, a maintainer makes and records the decision. Platform resolves decisions that materially affect licensing, security, or long-term direction.
